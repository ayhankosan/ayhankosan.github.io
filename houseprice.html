US State Housing Price Trends: Interactive Visualization of Six Decades of Market Evolution

Category Data Visualization, Web-Mapping, JavaScript
Date 2025

US State Housing Price Trends (1940–2000)

This interactive map visualizes housing price trends across the United States from 1940 to 2000, revealing patterns of growth and affordability challenges over six decades. This is an interactive choropleth map where you can click on any state to view detailed housing price statistics. Corresponding data visualizations and trend analysis appear below the map when a state is selected. The visualization shows how median home values adjusted for inflation nearly quadrupled over this 60-year period, rising from $30,600 in 1940 to $119,600 in 2000 nationwide.

Technical Context

The following technologies were used to create this visualization:

  • Leaflet.js and GeoJSON for interactive mapping
  • D3.js for data visualization of U.S. Census Bureau Historical Census of Housing Tables
  • JavaScript for time-series analysis and regional comparison
  • CSS-styled blue-scale choropleth for state price differentiation
  • JavaScript event listeners for user interaction
  • Promises for asynchronous data operations
  • HTML/CSS components for data display (tooltips, panels, legends)

The architecture follows a modular approach with separate functions for data fetching, map updates, chart rendering and color calculations. The data shows interesting regional patterns, with the District of Columbia having the highest median home values from 1940 to 1950, followed by Hawaii from 1960 onward. Southern states like Arkansas, Mississippi and Oklahoma consistently showed the lowest median home values throughout this period.
